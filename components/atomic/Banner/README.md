# Banner component

This component can be used to create a banner that spans the full width of the page and sticks to the either the top or bottom depending on the props passed in.

It uses a pure CSS approach to making the banner sticky.

There are several colors that the banner can be stylized with depending on the `theme` passed in:

- <span style="color:#3CAE3F">info</span>
- <span style="color:#FAB364">warning</span>
- <span style="color:#ED4C4C">error</span>
- <span style="color:#DCE0E3">(no theme passed in)</span>
